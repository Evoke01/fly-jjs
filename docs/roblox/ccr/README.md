# Change requests

Contracts (`CONTRACTS.md`, `Types.luau`, `Net/Protocol.luau`, `docs/roblox/schemas/`, the asset contract) are frozen once they are tagged. To change one, or anything outside your owned paths, add `CCR-<n>.md` here with:

- **Who:** your name and work item.
- **What:** the exact change.
- **Why:** what breaks or is impossible without it.
- **Impact:** every work item and agent it touches.

Priya (the Lead) accepts or rejects it in the same file; the owner of the path applies an accepted change.
