A Fruit Fly's Brain
Plays Roblox.

We took a mathematically accurate simulation of a real fruit fly's brain — 130,000 neurons, 50 million synaptic connections — and connected it to Jujutsu Shenanigans.

Watch the video by @FakeEvoke ↗

Installation

Download the code from GitHub and start training your own fruit fly.

# 1. Clone the repository
git clone https://github.com/Evoke01/fly-jjs.git
cd fly-jjs

# 2. Install dependencies
pip install -r requirements.txt

# 3. Start the Interactive CLI
python main.py

CLI Features

The updated terminal interface provides full control over the biological simulation.

Play (RL Loop)

The fly brain takes control, learning to fight via dopamine-driven plasticity.

Train (Imitation)

Play the game manually. The fly watches your screen and learns from your keystrokes.

Wipe Memory

Delete the fly's learned synaptic weights and start from a blank slate.

Check Updates

Automatically pull the latest code and patches from the GitHub repository.

Under the Hood

Unlike typical machine learning models that use mathematical arrays and backpropagation, this brain uses spikes — discrete electrical pulses.

The screen pixels are fed directly into the fly's retinal neurons (LC4, LPLC2). The signal cascades through 130,000 neurons down to the descending neurons in the ventral nerve cord, which trigger the keyboard presses. 

# Inject visual data into the retina
for i in range(64):
    injections.append((retina[i], pixels[i] * 1.5))

# Simulate one biological timestep
fired_neurons = brain.step(inject=injections)

# Evaluate descending neuron populations
fwd_rate = sum(1 for n in fwd_pop if n in fired_neurons) / len(fwd_pop)

# Trigger physical action
if fwd_rate > THRESHOLD:
    press_key("W")
