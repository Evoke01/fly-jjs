The Science

What is a Simulated Fly Brain?

In 2024, neuroscientists completed the full connectome of the fruit fly (Drosophila melanogaster). Every single neuron, every single synapse, mapped. The FlyBrain library turns this map into a working simulation.

🧬

Real Connectome Data

This isn't a toy neural network. It's a one-to-one simulation of an actual fruit fly's brain, built from electron microscopy scans of real brain tissue. Every neuron has a real biological name and type.

⚡

Spiking Neural Network

Unlike typical models that use math formulas, this brain uses spikes — discrete electrical pulses. When a neuron's voltage crosses a threshold, it "fires" and sends signals to thousands of connected neurons.

🪰

Hardwired by Evolution

A fruit fly's brain has been optimized by 200 million years of evolution. It knows how to find food, flee from threats, navigate in 3D space, and make split-second survival decisions — all with just 130,000 neurons.

🎮

Connected to Roblox

We feed the game's screen into the fly's visual neurons, let the brain simulate, then read which motor neurons fired and press the corresponding keys. The fly sees the game, thinks, and acts — all in real time.

The Pipeline

How Does the Fly Play the Game?

Every 50 milliseconds, the brain goes through a complete perception → thought → action loop. Here is exactly what happens in each cycle:

1

👁️ Screen Capture → Retina

The game screen is captured and downsampled to an 8×8 pixel grid — 64 intensity values representing what the fly "sees." This is injected as electrical current into LC4 and LPLC2 visual neurons (the fly's real looming and motion detection cells). Additionally, an opponent detection algorithm finds the enemy's position and size on screen.

2

🧠 Brain Simulation

The injected visual data flows through the connectome. 130,000 neurons update their voltages based on 50 million synaptic weights. Neurons that cross their firing threshold produce a spike, which propagates to all downstream neurons. The entire brain simulates in one timestep.

3

📊 Population Voting (Readout)

We read out the Descending Neurons (DNs) — these are the fly's motor command neurons that connect the brain to the body. Groups of 25-30 DNs are assigned to each action (forward, left, right, attack, dodge). If enough neurons in a group fire (above 12-18% threshold), that action is triggered. This is population coding — the same mechanism real brains use.

4

🎯 Action Execution

The winning actions are translated into real keystrokes via pydirectinput. Forward → W, strafe → A/D, attack → Left Click (M1), dodge → Q. The brain decides. We just press the buttons.

5

🔄 Arousal Feedback Loop

The fly's overall brain activity is tracked over time as an arousal level. As more neurons fire, the fly becomes more agitated — its thresholds drop, making it attack more aggressively and move more frantically. A calm fly explores. An aroused fly fights. Just like a real animal.

Advanced Systems

What Makes This Special

👁️

Dual Visual Input

The brain receives BOTH raw retinal data (8×8 pixel grid → LC4/LPLC2 visual neurons) AND processed opponent tracking data (position, size, threat level via FeatureDetectors).

🧠

Temporal Memory

A sliding window of 5 past brain states gives the fly short-term memory. It doesn't just react to the current frame — it remembers recent activity and makes smoother decisions.

🔥

Arousal System

Overall brain activity accumulates as "arousal." As the fly gets more stimulated, its action thresholds drop — it moves faster, attacks more, and becomes increasingly aggressive. A real biological feedback loop.

💨

Motion-Triggered Dodge

Frame-to-frame pixel differences detect sudden visual changes (explosions, attacks hitting you). When motion spikes AND dodge neurons fire, the fly reflexively dashes away — like a real escape reflex.

📊

Population Coding

Instead of one neuron = one action, groups of 20-30 neurons vote on each behavior. This is how real brains work — noisy individual neurons become reliable when averaged across a population.

🌋

INFERNO Heatmap

The live visualization uses the INFERNO scientific colormap with smooth temporal decay. Neurons glow bright when they fire and slowly fade — showing the brain's activity wave in real time.

The Core Brain Loop
